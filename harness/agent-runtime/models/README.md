# DSH model bindings

Selected original DSH model implementations are absorbed under src/dsh. The host accepts explicit native model adapters; runtime tests and the demo use scripted adapters. No live VLM provider has been configured or evaluated in this phase. ModelRegistry remains a target configuration interface.
