# Explicit role communication

[sessions.ts](src/sessions.ts) validates briefs and role tool authority, reserves assignment admission, creates independent DSH sessions and delivers explicit inbox messages. Native output/tool/TODO/status events feed upper projections. Sender identity is bound by application tools. Delivery waits for native session quiescence; durable distributed delivery and configurable report schemas remain pending.
