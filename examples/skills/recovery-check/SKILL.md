# Applicability

A placement goal remains unverified after an attempt. This is a synthetic
format example, not experience collected by an implemented Evolver.

# Planning cue

Before changing the instruction, compare the intended object binding with
what the latest evidence identifies. Ask for a new observation when identity
is ambiguous; the decision owner selects any retry or replan.

# Verification cue

Check the task's actual containment predicate using evidence from the stopped
attempt. Do not infer containment from proximity in one camera frame.
