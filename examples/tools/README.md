# Tools

`sam-segmentation.yaml` declares an unbound physical provider interface whose
input/output references map to the authoritative physical schemas. The running
native DSH binding uses granted evidence IDs and camera attachment IDs; see
[`robocasa-live.mjs`](../../examples/deployments/robocasa-live.mjs). The other tools are listed in
[the tool inventory](../../harness/agent-runtime/tools/definitions/planned-tools.json).
